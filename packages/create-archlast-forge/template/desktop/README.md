# __NAME__ desktop

A desktop app made with [Tauri](https://tauri.app). Tauri needs Rust and your platform's webview libraries: see [its prerequisites](https://tauri.app/start/prerequisites/).

__MODE_SECTION__

```bash
bun run dev      # tauri dev
bun run build    # tauri build: an installer in src-tauri/target/release/bundle
```

Before your first build, make the app's icons from one image: `bunx tauri icon path/to/icon.png` (the ones here are placeholders).
